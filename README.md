# 🛒 Amazon Clone (Static Web Page)

A responsive and accurate frontend clone of the Amazon homepage built completely from scratch using pure **HTML5** and **CSS3**.

This project demonstrates core layout techniques, custom flexbox alignment, complex multi-column footers, and pixel-perfect UI recreation.

---

## 🔗 Live Demo

View the live site here:  
👉 **https://hudakhan-codes.github.io/Amazon-Clone/**

---

## ✨ Key Features

* **Header Navigation:** Includes Amazon branding, deliver-to location, search bar, language/currency selector, and cart interface.
* **Hero Section:** Clean banner with gradient overlay and background positioning.
* **Product Grid:** Multi-box product showcase for various shopping categories.
* **Pre-Footer & Footer:** Multi-column layout featuring quick navigation links, region/currency selector, and back-to-top functionality.
* **Pure CSS Layouts:** Built without relying on external UI frameworks to master core CSS fundamentals.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure
* **CSS3:** Flexbox, Positioning, Custom Styling
* **FontAwesome:** Scalable vector icons
